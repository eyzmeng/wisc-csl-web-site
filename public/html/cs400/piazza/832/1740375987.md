**Edit!** Turns out history expansion does work in Bash (I just remembered [this legendary website](https://tldp.org/HOWTO/Bash-Prompt-HOWTO/x834.html)'s existence.) But you need a *slightly* different PS1 variable than `\#`: that is, `\!`:

```
\!
    The history number of this command.
\#
    The command number of this command.
````

You'll notice the similarity with tcsh's `%!`:

<pre><b>prompt</b>  The  string which is printed before reading each
        command from the terminal.  <b>prompt</b> may include
        any of the following formatting sequences (+),
        which are replaced by the given information:

        %h, %!, !
            The current history event number.
</pre>

Now, let's look at CSL's default Bash prompt:

<pre>[CSLID@vm-instunix-11] (1)$ <b>echo $PS1</b>
[\u@\h] (\#)$ </pre>

Ew, gross. They didn't even bother to use `\$` (which will change into `#` if you are root/uid=0---this is basic PS1 knowledge!) Now let me demonstrate how to *really* get a meaningful number:

<pre>[CSLID@vm-instunix-11] (2)$ <b>PS1='[\u@\h \w] (\!)\$ '</b>
[CSLID@vm-instunix-11 ~] (503)$ <b>cd cs400/P103</b>
</pre><div></div>
<pre>
[CSLID@vm-instunix-11 ~/cs400/P103] (504)$ <b>make &amp;&amp; make test</b>
make: Nothing to be done for `build'.
[test ok x1]
[CSLID@vm-instunix-11 ~/cs400/P103] (505)$ <b>!504</b>
make && make test
[test ok x2]
[CSLID@vm-instunix-11 ~/cs400/P103] (506)$ <b>!504</b>
make && make test
[test ok x3]
</pre>

Now it works just like csh! Actually, you can make it shorter. Maybe swap `\w` out for `\W`, or remove the `\u` that prints your CSLID on every line...
