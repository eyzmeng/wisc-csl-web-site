Description

iSongly is a song filter and display thing. It has a shell-like interface that interacts with an API that parses, filters, and outputs the titles of songs stored in a CSV file.

While iSongly was completed under the guidance and complete control of the course staff, isongly.py and the testing framework used to test various components of iSongly were developed independently. Those portions of the project will be open-sourced under the modified BSD license, while iSongly shall remain closed-source unless I am given the explicit permission to share it.
