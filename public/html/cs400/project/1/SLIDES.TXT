                           INSTALLATION (distribution)                          
                                                                                
   If you are not a system administrator or prefer not to install to the        
   whole system, you would need to configure $prefix.  Note that exporting      
   `prefix' does not work; you need to pass it to make(1) to override it.       
                                                                                
   For example, let's say `~/.local/bin' is on your PATH.  Then to install:     
                                                                                
       make dist prefix="$HOME/.local"                                          
       make install prefix="$HOME/.local"                                       
                                                                                
   To uninstall:                                                                
                                                                                
       make uninstall prefix="$HOME/.local"                                     
                                                                                
   This time you should not need root privilege.
